# 🔍 Regex Tester

> 正则表达式在线测试工具 — 实时匹配 · 替换调试 · 模式说明

## ✨ 功能

| 模块 | 功能 |
|---|---|
| 🎯 **匹配测试** | 实时正则匹配，输入即出，支持 150ms 防抖 |
| 🖍️ **高亮预览** | 测试文本中自动高亮所有匹配位置 |
| 🔢 **匹配详情** | 显示每个匹配的位置、内容、分组捕获（含命名分组） |
| 🔄 **替换模式** | 支持 `$1`、`$&`、`` $` ``、`$'` 等替换引用 |
| 🏷️ **常用模式** | 一键填入 Email / URL / 手机号 / 强密码 / 日期 / IPv4 / HTML 标签 |
| 🚩 **标志位** | g / i / m / s / u / y 可视化按钮切换 |
| 📖 **模式说明** | 自动解析正则表达式，逐段解释每个 token 含义 |
| 📝 **示例数据** | 一键加载测试数据 |

## 🛠 技术栈

- 纯 HTML5 + CSS3 + JavaScript
- 浏览器原生 RegExp
- 零外部依赖

## 🚀 部署

支持 Vercel / Netlify / Cloudflare Pages 等静态托管平台。

```bash
npx vercel --prod
```

## 🔒 隐私

所有处理在浏览器端完成，**文本不上传服务器**。
