Regex Tester 是什么？

一个用于 JavaScript 正则表达式实时匹配、替换调试、分组捕获和常用模式测试的在线工具。

主要功能

  • Live regex match highlighting
  • Capture group and named group display
  • Find and replace testing
  • Common regex presets
  • JavaScript regex flags
  • Pattern explanation hints

适合场景

  • 开发、调试或发布前的日常处理
  • 在浏览器端快速完成任务，减少数据上传
  • 为技术文档、测试数据或线上内容做准备

示例工作流

  1. 输入你准备在项目中使用的表达式和 flags。
  2. 同时加入应该匹配和不应该匹配的样例。
  3. 并排检查捕获组、替换结果和高亮匹配。
  4. 复制到代码前，先覆盖边界情况和异常输入。

安全使用提示

  • 处理日志、邮件或用户内容时使用脱敏样本。
  • 用较长输入测试，避免表达式过慢或匹配范围过宽。
  • 交给别人维护前，记录每个捕获组的含义。

常见问题

使用哪个正则引擎？

使用浏览器内置的 JavaScript 正则表达式引擎。

支持正则替换吗？

支持。切换到替换模式后，可使用 $1、$& 等引用并实时预览结果。

支持命名分组吗？

支持浏览器可用的命名捕获分组，并会在匹配详情中显示。

测试文本会上传吗？

不会。匹配和替换都在浏览器端完成。

测试说明与限制

本工具使用浏览器提供的 JavaScript 正则表达式引擎。复制到 Python、Java、Go、.NET、数据库或命令行工具后，语法和行为可能不同。上线前需要在实际运行环境中复核标志位、Unicode、捕获组和替换语法。

性能测试不能只看短文本。应加入一段“几乎匹配”的长输入，检查嵌套量词和歧义分支是否造成明显变慢；对于有明确结构的格式，应优先使用解析器。
